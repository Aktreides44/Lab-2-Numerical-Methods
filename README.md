# Numerical Methods Lab 2

## Topic
Floating-Point Arithmetic and the Basel Problem.

## Description
This project investigates floating-point arithmetic using the Basel series. The implementations calculate the series in C++, Python, and Julia, examine summation stagnation, compare forward and reverse summation, and measure execution times.

## Project Structure
- `cpp/` – C++ implementations
- `python/` – Python implementations and plotting script
- `julia/` – Julia implementations
- `results/` – Numerical results and benchmark CSV files
- `plots/` – Generated plots

## Requirements
- GCC/G++ with C++17 support
- Python 3
- Julia

## Running the Code
Run the relevant source files using the appropriate compiler or interpreter. For example:

```bash
python3 python/stagnation.py
python3 python/task2_analysis.py
python3 python/task3_summation.py
python3 python/task4_benchmark.py
python3 python/task5_plots.py
```

C++ and Julia files should be compiled or run using their respective tools.

## Environment
The experiments were performed on Ubuntu through WSL2, using an Intel Core i5-1235U processor and 16 GB RAM.
